====================================================
  ralvye.com - CV en 3D
  Pagina personal estilo isla interactiva en Three.js
====================================================


VER LA PAGINA
-------------
  Abrir web/index.html con cualquier servidor estatico, por ejemplo:
    npx serve web


ESTRUCTURA DE ARCHIVOS
-----------------------
  cv-page/
  |-- INSTRUCCIONES.txt <- Este archivo
  |-- web/              <- Sitio compilado (listo para servir)
  |   |-- index.html
  |   |-- cv.html       <- CV en texto, version simple
  |   |-- assets/       <- JS y CSS compilados
  |   `-- images/
  `-- source/           <- Codigo fuente (para modificar/desarrollar)
      |-- index.html
      |-- package.json
      |-- public/       <- Archivos estaticos (cv.html, sitemap, imagenes)
      `-- src/
          |-- main.js     <- Escena 3D, camara y navegacion
          |-- content.js  <- Textos del CV (cambiar aqui el contenido)
          `-- style.css   <- Estilos de la tarjeta y de la barra de navegacion


SI QUIERES MODIFICAR EL CODIGO FUENTE
---------------------------------------
  Requisitos previos:
    - Node.js 18+   -> https://nodejs.org  (descargar LTS)

  Pasos:
    1. Abrir terminal (CMD o PowerShell) en la carpeta source/
    2. Instalar dependencias:
         npm install
    3. Iniciar servidor de desarrollo (con recarga automatica):
         npm run dev
    4. Abrir en el navegador: http://localhost:5173/
    5. Editar content.js o main.js y los cambios se aplican al instante

  Para generar una nueva version compilada:
         npm run build
  Luego copiar el contenido de source/dist/ dentro de web/
  (reemplazando los archivos anteriores) y abrir web/index.html.


TECNOLOGIAS UTILIZADAS
-----------------------
  - Three.js 0.183    : Motor de renderizado 3D
  - Vite 7            : Bundler y servidor de desarrollo


NOTAS TECNICAS
--------------
  - La escena es una isla procedural: el terreno, los arboles y el campo de
    estrellas se generan en el navegador, sin modelos 3D externos.
  - Cada estacion de la isla corresponde a una seccion del CV (content.js).
  - Conduccion: flechas o WASD para manejar el auto; al pasar por un anillo se abre su seccion.
    En el celular se usan los botones tactiles de la pantalla.
  - Los botones de la barra inferior (flechas y puntos) saltan directo a cada seccion.
